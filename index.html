Logic and Algebraic Specifications

Introduction

Descriptive specifications describe what a software system should do rather than how it should be implemented. They use mathematical concepts to define system behaviour.

Two major approaches:

  • Logic Specifications
  • Algebraic Specifications

1. Logic Specification Simulator

Example: Bank Withdrawal System

A customer can withdraw money only if:

  • Account is active.
  • Withdrawal amount is greater than zero.
  • Sufficient balance is available.

Logic Specification Rules

Precondition

Account Active AND Amount > 0 AND Amount ≤ Balance

Postcondition

New Balance = Old Balance - Withdrawal Amount

Invariant

Account Balance ≥ 0

2. Algebraic Specification Simulator

Example: Stack Data Structure

Algebraic Specification Equations

1. Create an empty stack:

isEmpty(create()) = true

2. Push an element:

isEmpty(push(S,x)) = false

3. Get top element:

top(push(S,x)) = x

4. Remove top element:

pop(push(S,x)) = S

3. Comparison of Specifications

Basis Logic Specification Algebraic Specification
Meaning Uses logical statements and conditions. Uses operations and equations.
Focus Conditions and properties. Behaviour of abstract data types.
Elements Preconditions, postconditions, invariants. Operations, signatures and axioms.
Example Bank withdrawal system. Stack and Queue.
Purpose Defines system correctness. Defines data type behaviour.
